Page access

Sites allowed to read page context

When a snippet uses a ${page:url}, ${page:title}, ${page:domain}, or ${page:selection} token, the extension asks the first time it runs on a site. Sites you chose "Always allow" for are listed below. Remove one to be asked again next time.

Supported tokens

  • ${date} inserts today as YYYY-MM-DD.
  • ${clipboard} inserts the current clipboard text.
  • ${input:name} asks for a value when expanding (one form for all inputs).
  • ${cursor} places the caret after the snippet expands.
  • ${page:url}, ${page:title}, ${page:domain}, ${page:selection} pull in the current page (asks per site — see the Page access tab).

How expansion works

  • Works in input, textarea, and basic contenteditable fields.
  • Press space to expand and keep the space.
  • Press tab to expand without adding a tab character.
  • Best fit today: chat interfaces like ChatGPT, Claude, Gemini, and similar editors.
  • The starter snippets each demonstrate a token — open one to see how it is written.

Starter snippets

Restore the built-in starter set (about a dozen examples, one per token). This replaces your current snippets but keeps your settings and allowed sites. Use it after an update, or to start over.

Snippet packs

A pack is a JSON file: either a bare array of snippets or an object with a snippets array (an exported file works as-is). Installing a pack merges it into your set; duplicate triggers are skipped by default.

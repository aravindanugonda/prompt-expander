Prompt Expander (>_)

Reusable prompts for chat tools

Type a trigger like >_use-analyzer-prompt in a text field, then press space or tab to expand it.

Snippet editor

Create or update a snippet

Supported tokens

  • ${date} inserts today as YYYY-MM-DD.
  • ${clipboard} inserts the current clipboard text.
  • ${input:name} prompts for a value at expansion time.
  • ${cursor} places the caret after the snippet expands.

How expansion works

  • Works in input, textarea, and basic contenteditable fields.
  • Press space to expand and keep the space.
  • Press tab to expand without adding a tab character.
  • Best fit today: chat interfaces like ChatGPT, Claude, Gemini, and similar editors.
